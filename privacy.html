Privacy policy

exchange-sync is a personal tool used only by its owner.

  • It accesses Google Calendar and Gmail solely to write the owner's own work calendar events and emails into the owner's own Google account.
  • It does not read existing Gmail messages.
  • No data is collected, sold, shared with third parties or used for advertising.
  • Access tokens are stored only on the owner's private server and can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
